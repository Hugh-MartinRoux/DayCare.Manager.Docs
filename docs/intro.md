# Introduction

Welcome to the DayCare Connect API documentation.

DayCare Connect allows external systems to access your DayCare Manager system's data which allows you to interact with the system via a third-party website or mobile app.

## Prerequisites

In order to make use of the DayCare Connect API, you will need:

- An existing My-DayCare Manager account.
- Subscription to the DayCare Connect service.

## Before you start

It is recommended that you reach out to your customer relations manager and notify them of your intentions to make use of the DayCare Connect API.

If at any point, you require additional support, please don't hesitate to reach out to support@mydaycare.com to get access to our experienced support specialists who will be able to assist you with any issues you might encounter or answer any of your questions. 

We are excited to start this journey with you.

Good luck!
