# Getting Started

Once you have been subscribed to the DayCare Connect API, you will notice that a DayCare Connect page becomes available in your DayCare Manager system.

From here, various aspects of the API can be configured. 

Additionally, this is where you can create your API keys and manage your Connect clients.

## How to access the DayCare Connect page in DayCare Manager

To access the DayCare Connect configuration page, follow these instructions:

1. Login to the DayCare Manager system using your My-DayCare account.
2. In the navigation pane on the left, go to Advanced > Configuration > DayCare Connect.

For a detailed guide to configuring DayCare Connect, see the [DayCare Connect Configuration Guide](./guides/configuring-daycare-connect.md).
